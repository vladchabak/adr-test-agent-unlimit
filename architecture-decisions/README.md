# Architecture Decisions

This repository contains the Architecture Decision Log (ADL) and individual Architecture Decision Records (ADRs) for our microservices ecosystem.

## Structure

- `ARCHITECTURE_DECISION_LOG.md` — Single log file with short entries for every architecturally significant change
- `adr/` — Directory containing detailed ADR documents for major changes

## Services Tracked

- **order-service** — Order management microservice
- **payment-service** — Payment processing microservice
